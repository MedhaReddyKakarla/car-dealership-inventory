\# VeyraDrive — Car Dealership Inventory System



VeyraDrive is a full-stack car dealership inventory management system built with React and FastAPI.



It provides secure authentication, vehicle inventory management, search and filtering, vehicle purchasing, and admin-only stock management.



\## Features



\- JWT-based user authentication

\- Role-based admin authorization

\- Add, view, edit, and delete vehicles

\- Search and filter inventory

\- Vehicle purchase functionality

\- Automatic stock quantity updates

\- Admin-only vehicle restocking

\- Out-of-stock handling

\- Responsive React interface

\- RESTful FastAPI backend

\- PostgreSQL database

\- Automated backend tests using Pytest
